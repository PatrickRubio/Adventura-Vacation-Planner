# Adventura-Vacation-Planner
Adventura - Vacation Planner Mobile App
Android | Java | SQLite (Room) | MVVM Architecture

A mobile application that allows users to create, manage, and store vacation plans using Android Studio, Java, and SQLite (Room). Designed as part of WGU’s Software Engineering capstone, this app demonstrates clean architecture, persistent storage, and responsive Android UI.

Features

Create and save vacation trips
Persistent local data storage using Room (SQLite)

Add trip details:
Destination
Dates
Lodging
Activities

MVVM architecture
XML-based UI layouts
Tested on emulator and Android device

🛠 Tech Stack

Languages: Java
Architecture: MVVM, Repository pattern
Database: SQLite (Room Library)
Tools: Android Studio, Git, GitHub, Gradle
